# Technology Stack

**Analysis Date:** 2026-08-19

## Languages

**Primary:**
- Python 3.12+ - Backend API and business logic (`app/*.py`, `app/services/`, `app/api/`)
- JavaScript (ES modules) - Frontend PWA and Capacitor shell (`app/static/js/`, `package.json` scripts)

**Secondary:**
- SQL - Database queries via SQLAlchemy (`app/models.py`, `app/migrations.py`)
- Java/Kotlin - Android build (generated by Capacitor, `android/` directory)

## Runtime

**Environment:**
- Python 3.12+ (required in `pyproject.toml`)
- Node.js (for Capacitor CLI and npm/yarn, optional for local dev)
- Docker runtime (production deployment target)

**Package Manager:**
- uv (Python) - Primary package manager
  - Lockfile: `uv.lock` (461KB, frozen dependencies)
  - Installation: `uv sync` (includes dev dependencies) or `uv sync --no-dev` (production)
  - Config: `pyproject.toml` with dependency groups

## Frameworks

**Core:**
- FastAPI 0.115+ (`app/main.py`, `app/api/`) - REST API framework with async support
- Uvicorn 0.30+ - ASGI server for running FastAPI application
- SQLAlchemy 2.0+ (`app/models.py`, `app/db.py`) - ORM for data persistence
- Pydantic 2.7+ (`app/schemas.py`, `app/config.py`) - Data validation and serialization
- Pydantic Settings 2.3+ - Configuration management from environment variables

**MCP (Model Context Protocol):**
- FastMCP 2.0+ (`app/mcp.py`) - MCP server for AI agent integration (Claude, ChatGPT, Gemini)

**Frontend (No Framework):**
- Vanilla JavaScript with ES modules - Pure vanilla JS, no React/Vue/Svelte
- No build tool/bundler - Assets served directly from `app/static/`
- Web APIs (Fetch, Service Worker, Local Storage, IndexedDB)

**Mobile:**
- Capacitor 8.4.2 (`package.json`, `capacitor.config.json`) - Bridge between web app and Android
- Capacitor CLI 8.4.2 - Build and sync tools for Android packaging
- Capacitor Core 8.4.2 - Runtime APIs
- Capacitor Local Notifications 8.2.1 (`app/api/push.py`) - Native push notification support

**Testing:**
- pytest 8.0+ (`tests/`, `pyproject.toml`) - Unit and integration test runner
- pytest-asyncio 1.4+ - Async test support
- pytest-cov 5.0+ - Code coverage reporting
- httpx 0.27+ - Async HTTP client for testing APIs
- Playwright 1.61+ (`app/static/js/`, `tests/e2e/`) - Headless browser for E2E frontend tests

**Build/Dev:**
- ruff 0.5+ - Python linter and formatter (`pyproject.toml` config)
- Gradle - Android build tool (via Capacitor)
- npm/npx - Node package runner for Capacitor CLI

## Configuration

**Environment:**
- Configuration via environment variables in `.env` file
- Settings class: `app/config.py::Settings` - Uses Pydantic for type-safe env loading
- Key env vars (template in `.env.example`):
  - `LIFTLOG_TOKEN` - Demo mode shared Bearer token (optional, F149)
  - `LIFTLOG_SECRET_KEY` - CSRF token HMAC key (optional, generated if missing)
  - `LIFTLOG_DB` - SQLite data database path (default: `./liftlog.db`)
  - `LIFTLOG_CONTROL_DB_PATH` - Control database path for auth/users (default: `./control.db`)
  - `LIFTLOG_USER_DATA_DIR` - Per-user database directory (default: `./users`)
  - `LIFTLOG_GOOGLE_CLIENT_ID` - Google OAuth client ID for authentication
  - `LIFTLOG_VAPID_PRIVATE_KEY` - PKCS8 DER base64url key for web push
  - `LIFTLOG_VAPID_PUBLIC_KEY` - Base64url compressed public key for web push
  - `LIFTLOG_VAPID_SUBJECT` - VAPID claims subject (default: `mailto:admin@example.com`)
  - `LIFTLOG_ENV_LABEL` - Environment label: `prod` or `dev` (default: `prod`)
  - `LIFTLOG_RELEASE_DIR` - Directory for app release APKs (default: `./release`)

**Build:**
- `pyproject.toml` - Python project metadata and dependencies
- `uv.lock` - Frozen dependency versions
- `Dockerfile` - Docker image configuration for production deployment
- `capacitor.config.json` - Capacitor configuration for Android app
- `package.json` - Capacitor/Node dependencies

## Platform Requirements

**Development:**
- Python 3.12+ (enforced by `requires-python`)
- uv package manager
- Playwright (for E2E testing): `uv run playwright install chromium`
- Android SDK/NDK (if building APK locally)
- Node.js/npm (for Capacitor CLI)

**Production:**
- Docker runtime (preferred method via `Dockerfile`)
- Docker Compose (optional, defined in `docker-compose.yml`)
- Alternatively: Python 3.12 with uv, uvicorn as ASGI server

**Deployment Target:**
- Docker container (Python 3.12-slim base image)
- Uvicorn listening on port 8000
- Volume mounts for persistent data: `/data/` contains `liftlog.db`, `control.db`, user databases
- Environment: `PYTHONPATH=/app`, `UV_COMPILE_BYTECODE=1`, `UV_LINK_MODE=copy`
