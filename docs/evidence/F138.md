# F138 — E2E 腳本在預設 cp950 主控台下會 UnicodeEncodeError 中斷（假訊號）

驗收日：2026-08-13。全程在 **cp950 主控台、未設 `PYTHONUTF8` 與 `PYTHONIOENCODING`** 下執行。

## 環境前提（重要）

`chcp` = 950、`Get-WinSystemLocale` = `zh-TW`、`HKLM\...\Nls\CodePage\ACP` = `950`。

`PYTHONIOENCODING=utf-8:surrogateescape` 是 **Claude Code harness 注入的 process 層變數**——
User 與 Machine 層皆為空。取證前以 `$env:PYTHONIOENCODING=$null; $env:PYTHONUTF8=$null; chcp 950`
還原成 Ryan 實際的預設主控台。

**這代表 agent 透過 harness 跑 E2E 永遠看不到這個缺陷，人在自己的 PowerShell 跑就會中斷。**
