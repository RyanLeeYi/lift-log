# F127 — 原生端結束的休息，回 app 後不得復活

真機驗收（Galaxy RF8NB0BSEFE，dev v137，2026-08-04 10:14–10:26）。

做法：原生在**明確結束**這輪時（ACTION_STOP／ACTION_STOP_FROM_NOTIFICATION 那條分支）
寫一個時間戳到 SharedPreferences `liftlog_rest_state.stopped_at`；前端開機時經
`RestTimerPlugin.getRestStoppedAt()` 取件，`stoppedAt > state.restStartedAt` 就丟掉快照
（呼叫 stopRestTimer()）。存時間戳而非布林值，正是 ④ 要的區分方式。

⑥-1 PASS｜10:15 開一輪（120s）→ 最近使用清單滑掉 app（服務仍 3 行）→ 通知按「停止」
   → 服務 0 → 重開 app → 服務仍 0、計時頁**無倒數卡**、主按鈕是「完成這組」。

⑥-2 PASS（F66 不回歸）｜10:19 開一輪 → 滑掉 app → **不按任何鈕** →
   `adb shell am force-stop`（服務 0）→ 重開 app → 服務回來、`channel=rest-timer`、
   計時頁倒數卡 00:37 / 120s 完整還原，兩組紀錄都在。
   同時驗到「舊標記不污染新一輪」：⑥-1 在 10:17 留下的標記早於這輪的 startedAt（10:19），
   比大小自然放行。
