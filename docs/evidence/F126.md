# F126 — 倒數中的通知也要有「停止」與「回到 app」，且回到 app 不停倒數

真機驗收（Galaxy RF8NB0BSEFE，dev v136，2026-08-04 09:29–09:48）。

探針：`adb shell dumpsys activity services com.ryanleeyi.liftlog.dev` 的
`foregroundNoti=Notification(channel=... actions=N)` — 一次答出通知在不在、掛哪個頻道、幾顆鈕。

① 倒數中 id 2001 → `channel=rest-timer ... actions=2`；
   `dumpsys notification --noredact` 展開為 `[0] "停止" -> startService`、
   `[1] "回到 app" -> startActivity`。通知欄實際畫面見截圖 s13（「休息中・剩餘 0:42」＋兩顆鈕）。
② 兩張表的差異逐條實測，見 ⑦。
③ 導頁走既有 focus 事件，休息未被中斷（⑦-1、⑦-3 的倒數都還在跑）。
④⑤ 暫停態實測 `actions=2`（09:41 暫停後探針）。
⑥ 不回歸：倒數那則始終 `channel=rest-timer`、`importance=2`（LOW），F123 ⑤ 未破壞；
   時間到那則仍為 `channel=rest-alarm ... category=alarm actions=2`。

⑦ 四條路徑：
1. app 前景・非計時頁・倒數中 → 按「回到 app」→ 跳到肩推第 4 組計時頁，
   卡片顯示 00:13 / 150s 仍在跑，服務仍活（3 行 RestTimerService）。PASS
2. 同上 → 按「停止」→ 通知消失、`dumpsys activity services` 0 行（無孤兒服務）、
   app 側無休息卡、主按鈕回「完成這組」。PASS
3. app 背景（HOME）・倒數中 → 按「回到 app」→ app 回前景並跳到槓鈴臥推第 2 組計時頁，
   倒數 00:45 / 90s 仍在跑。PASS
4. 時間到的 heads-up（id 2003）→ 按「回到 app」→ 跳到槓鈴臥推第 3 組計時頁
   且服務歸零（＝仍是停止＋導頁），行為與 F123 ④ 相同、未被本 feature 改到。PASS
